# Forge

Личная система spec-driven-разработки поверх Claude Code: анкета → авто-research → брейншторм → спека → автономная стройка MVP с неблокирующими чекпоинтами через Telegram.

Идеология — по мотивам [github/spec-kit](https://github.com/github/spec-kit), реализация — собственный набор Claude Code skills.

**Статус:** идёт реализация первой версии. Что уже работает и что осталось — в [docs/STATUS.md](docs/STATUS.md); задачи — в [Issues](https://github.com/GarroV/forge/issues).
