# Служебный прогон: сокращалка ссылок, 30–31.07.2026

Первый полный прогон системы — от одной фразы до работающего MVP, без владельца.
Продукт (`~/Documents/projects/forge-smoke-urlshort`) был **выбрасываемым** и удалён
после прогона: он существовал только чтобы обкатать систему. Здесь оставлены два
файла, которых больше нет нигде и на которые опираются утверждения в
[../../OVERVIEW.md](../../OVERVIEW.md).

| файл | что это |
|---|---|
| [journal.md](journal.md) | журнал стройки, 33 записи append-only: обе приёмки, возврат блока, обе сверки со спекой, собственные ошибки диспетчера |
| [retro.md](retro.md) | разбор прогона, из которого выросли задачи #12–#15 беклога |

**Чем этот прогон ценен.** Не тем, что продукт получился (120 тестов, покрытие 99%,
сквозной сценарий в живом браузере), а тем, что нашёл **семнадцать дефектов самой
системы** — все запуском, ни один не нашёлся бы чтением кода. Шесть из них в
действиях, выполненных строго по инструкции, то есть инструкция их допускала.

Журнал стоит читать как доказательство несущих свойств: по нему видно, что
блок-агент умер посреди задачи и работа не потерялась; что приёмка **не приняла**
блок и вернула его; что сверка свежим взглядом нашла недоделанную обязательную
историю, которую пропустили все проверки до неё.

Продукт удалён вместе с базой `urlshort`. Воспроизводить его незачем: он был
репетицией, а не пилотом.
